# 知到学习助手 v0.4.8（提交后直接恢复视频）

在本机读取自己账号的课程列表和视频章节目录，可启动独立 Chrome 自动播放、播完切下一节，并接入自定义 AI 处理视频随堂练习。独立工具，非智慧树官方产品。

## 启动

需要 Python 3.10 或更高版本，以及已安装的 Google Chrome。在此文件夹打开终端：

```bash
python3 -m pip install -r requirements.txt
python3 server.py
```

Windows 可把 `python3` 换为 `py`。打开 <http://127.0.0.1:8765>，退出用 Ctrl+C。端口占用时使用 `python3 server.py --port 8766`。

## 读取自己的课程

1. 在浏览器正常登录智慧树，打开开发者工具 → Network（网络）。
2. 点击课程列表或 `getLoginUserInfo` 请求，在 Headers → Request Headers 找到 Cookie，复制其完整值。不要复制 Set-Cookie，也不要把 Cookie 发给别人。
3. 回到本程序，点“接入设置”，粘贴 Cookie；如果同一请求有 Authorization，也一起填写。Token 可留空。
4. 点“暂存会话”，关闭设置，点“读取平台课程”。
5. 点击课程卡片，自动读取该课章节。失败可以点“同步目录”重试。

当前支持共享课程的进行中/已结束列表，以及校内课程列表；共享视频课程可读取章节。校内翻转课目录和其他课程类型尚未接入，界面会说明限制。空响应或请求失败不会伪装成零门课程。

程序自动处理公开前端所使用的参数协商、`secretStr` 封装，以及视频服务的单点登录。**不把首页的 SESSION 直接复制给视频服务**，而是使用原样的 SSO Cookie，让平台为视频服务签发独立的内存会话。

如果提示视频服务登录失效，请在智慧树原网页打开视频课程并完成平台要求的登录或验证，重新获取完整 Cookie（需有有效 CASTGC）。程序不会绕过验证码、课程权限或诚信承诺。

## 启动自动学习

1. 暂存 Cookie → 读取平台课程 → 选择目标课程。
2. 如果希望弹题也自动处理，先在“接入设置”配置 AI 地址、模型和 API Key，再勾选“开启 AI 自动处理视频随堂练习”。不勾选时会等待人工答题。
3. 默认勾选“从未学习的章节开始学习”。启动后读取原页面成功返回的章节与学习进度，按目录顺序选择第一节未开始的视频；已完成、已开始但未完成的课时均不作为起点。取消勾选时由你手动选择起点。
4. 点“启动当前课程自动学习”。程序打开一个独立 Chrome 窗口，不使用你平常 Chrome 的配置文件。
5. 首次进入若出现平台提示，请自己处理；必要时点一次播放。之后程序观察原视频播放器，真实播放结束后点击下一节。若已没有未开始的课时，程序暂停并提示，不会从第一节重播。
6. 页面上的“暂停 / 继续 / 停止”控制当前任务。“继续”会明确请求恢复播放；平台弹窗仍在时显示具体等待原因，弹窗等待不会锁成手动暂停，也不会每轮反复暂停手动播放的视频。验证码、人脸、签到、承诺书、未知页面需要人工处理。不要关闭本地服务；关闭受控浏览器会结束任务。

起点定位当前适配共享课标准视频页的 `videolist` / `queryStuyInfo` 响应和 `.chapterScrollbar` 目录。智慧慕课等其他页面尚未适配该功能；无法识别进度或目录时会暂停，可取消起点选项改为手动选课时。起点选项只决定启动位置，后续按平台下一节顺序播放。若定位失败并已提示等待人工，手动选定课时后点击“继续”，将退出本次起点定位并按所选课时播放。

自动模式目前允许共享视频页和智慧慕课入口。智慧慕课优先使用目录中的当前课时与实际视频节点定位下一课时；旧版页面使用已确认的 `#nextBtn`；弹题支持旧版 `#playTopic-dialog` 中明确说明不影响作业、考试成绩的练习，以及智慧慕课新版 `.ai-class-exercise-dialog` 中标题为“AI随堂练习”的视频练习。新版弹窗不声明是否计分，程序不承诺其不影响课程成绩。其他页面结构会暂停，不猜测点击。

**自动模式的持续播放和弹题流程尚未使用真实账号完成长时间联调，不应把“自动逻辑测试通过”理解为已验证整门课程能无人值守完成。** 本次没有调用你的付费 AI，也没有替你自动完成整门课程。课程列表与目录读取仍保留上一版实测记录。

播放使用原播放器，平台自行记录其正常进度；程序不修改 currentTime/playbackRate、不生成或调用学习时长上报 API、不改写 isTrusted、不修改平台检测逻辑。AI 作答通过正常浏览器点击现有选项，不直接调用作业、考试或答案提交接口。

停止会等待当前网络请求返回再退出；不会在收到停止指令后继续点击答案。模型配置在启动时读取，更换 AI 配置需停止后重新启动任务。

## 配置 AI

在“接入设置”中填写服务商提供的完整 HTTPS `chat/completions` URL、模型 ID、API Key。程序不会自动添加路径。保存后显示“已配置 · 未验证”。费用由你配置的服务商收取。

手动“AI 学习助手”答疑面板与接口已删除。AI 配置仅用于自动处理视频弹题；开启后将当前可见题目与选项发送给所配置的 AI，不发送平台 Cookie、Token。模型可能答错或产生费用，图片题和低置信度回答会交给人工处理。

## 凭据与数据

- 仅绑定 127.0.0.1，校验 Host、Origin 和随机本机请求令牌，适合单用户个人电脑。不要代理到公网。
- Cookie、Authorization、API Key 与视频服务 CookieJar 只存在本机服务内存，不写日志和配置文件，不回显；退出后清空。
- 同一服务实例的窗口共享会话。更换账号后重新读取课程。
- 平台凭据只用于智慧树 HTTPS 域名；单点登录只允许智慧树域名内的 HTTPS 跳转，禁止把凭据转发到其他网站。
- AI Key 仅发送到你明确填写的地址，请确认地址可信。
- 清除凭据无法撤回已在执行的请求，也不等于在智慧树退出账号或撤销平台凭据。
- 页面课程快照刷新后需重新读取。JSON 导入、示例文件和手动导出脚本仍可作为备用方式。
